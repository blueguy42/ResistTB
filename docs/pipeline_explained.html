ResistTB pipeline explained

Steps, tools and algorithms, and how to read the two pipeline diagrams. 25 October 2026. All results are in silico.

ResistTB turns 456 public M. tuberculosis genomes (Bandung 222, Guangdong 173, Tamil Nadu 61) into qPCR primers and allele-specific probes for 192 WHO drug-resistance variants, and explains the result in a chat interface and a target library. It is live at resist-tb.afanhandoyo.com. Nothing has been tested in a tube.

Overview

  1. A. Per-isolate processing (cloud VM, diagram 1, finished): public reads become variant calls plus lineage and drug-resistance calls, stored in a bucket.
  2. B. Design library (Python, diagram 2): the variant calls become ranked primer and probe designs with coverage by region and lineage, specificity and multiplex checks.
  3. C. Agent and interface (diagram 2): a Gemini agent turns a chat request into calls to the design library and explains the report; the API and web page run in one Cloud Run container.

Stage A: per-isolate processing (diagram 1)

Modelled on the Nextstrain TB build, this stage ran 456 isolates on one cloud VM in two runs, 6 at a time (3 threads each): Bandung (222) in about 9.5 hours and Guangdong plus Tamil Nadu (234) in about 5 h 40 min. Median seconds per isolate were about 851 (Bandung), 515 (Tamil Nadu) and 436 (Guangdong). The VM has been deleted; results are in the bucket. Snakemake runs one rule per isolate in a fixed random order, so partial results are a fair sample.

Stage B: design library (diagram 2)

Python code (src/genohack/) that designs one assay in seconds. The key idea is to design oligos on the population consensus of the 456 pooled isolates, not on H37Rv, so a base that differs from H37Rv in every isolate still counts as conserved.

Scoring

The overall score is a transparent heuristic with hand-chosen weights, not a fitted model.

overall = 0.30 C + 0.30 T + 0.20 S + 0.20 E

  • C, conservation = 100 × exact matches / isolates.
  • T, thermodynamics = mean of five terms: probe Tm gap (target 8 C), primer Tm match (3 C), probe Tm 6-12 C above primers, worst cross-dimer, worst hairpin.
  • S, specificity = 100 - 25 × hits (H37Rv near-matches plus predicted off-target products).
  • E, WHO evidence = best positive predictive value for the exact change, as a percentage.

Example: inhA c.-15C>T scores C 97, T 84, S 100 and E 97, giving 94.

Limitations

  • In silico only: Tm, dimer and probe-gap values are model estimates.
  • In-sample coverage: oligos were designed and measured on the same 456 isolates; the held-out test on 779 other Indonesian runs and the leave-one-region-out test are not done.
  • Few resistant isolates for some targets: for example gyrA D94G has only 6 carriers, so mutant probes are designed from the expected change.
  • Regions are coarse: one label per study, and Tamil Nadu (61 isolates) is small and lineage-1 heavy. Four isolates look contaminated or mixed and are still included.
  • Not every variant: 13 WHO variants (dense or indel-rich sites in rpoB and pncA, and katG S315R) are not designed, and a full rifampicin assay needs more than one rpoB probe. 20 designs still score 0 for specificity.
  • Thresholds: roughly half are standard qPCR rules, the rest are choices made here and not yet cited in one settings file.
  • Prior work is not in the pipeline: TOAST supplied the gene annotation file and informed thresholds; PrimeGen informed the design ideas.
